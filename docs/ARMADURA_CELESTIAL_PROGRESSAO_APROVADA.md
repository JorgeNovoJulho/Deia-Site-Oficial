- São exatamente **nove peças** para completar a Armadura Celestial do Alvorecer.
- A primeira recompensa é identificada no PDF como **Grevas (Botas) sagradas**. Não inventar nomes das outras peças.

- A cada reino concluído, o sistema de jogo deve registrar a peça, mas **nenhum script Godot foi alterado nesta revisão documental**.

- Os fragmentos do Atlas das Constelações Perdidas e as joias de ataque/defesa são progressões separadas das peças principais.
