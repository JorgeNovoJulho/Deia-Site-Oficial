Entrar com GitHub

O painel edita o repositório oficial por meio da API GitHub. Apenas contas com autorização de escrita conseguem publicar. Utilize um token fine-grained com acesso somente ao repositório Deia-Site-Oficial e permissão Contents: Read and write. O token permanece apenas na memória desta aba; não é salvo em cookies ou armazenamento local.

Não use a senha de e-mail ou GitHub neste formulário. Gere um token com permissões limitadas em GitHub → Tokens fine-grained.

As alterações só ficam públicas após clicar em Publicar. Mídias devem respeitar os direitos autorais e a lore aprovada.

Editar seções do site

Selecione uma seção e altere os textos exibidos, títulos, descrições e URLs de imagens. Campos editáveis aparecem abaixo. Use o botão de publicação somente após revisar as alterações.

Gerenciar trilhas por card

Cada item corresponde a um card do site oficial. Escolha a faixa, envie um MP3/OGG ou associe um áudio já enviado. Ouça, pause, substitua e retire a música do card. A publicação atualiza o catálogo do site.

Vídeo em destaque da página inicial

Envie MP4/WebM para assets/video/ usando a biblioteca de arquivos, depois associe aqui o caminho publicado. Sem vídeo configurado, será mostrado o aviso de conteúdo em preparação.

Biblioteca de mídia

Envie imagens WebP/PNG/JPG ou áudio MP3/OGG para as pastas do site. Upload não insere automaticamente a mídia na página: depois, edite o caminho de uma imagem na seção correspondente. Para músicas, utilize o editor de arquivos para adicionar a entrada no catálogo ou atualizar a página.

Editor de arquivos

Editar arquivos JSON, Markdown, HTML, CSS e JavaScript exige cuidado. Um arquivo inválido pode impedir o carregamento do site. Não envie segredos ou material narrativo confidencial ao repositório público.
